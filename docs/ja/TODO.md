# MyMsg 開発タスクリスト (TODO)

本書は、`MyMsg` の実装済み機能（Completed）および将来の機能拡張ロードマップ（Planned / Backlog）を管理するタスクリストです。

---

## 1. 実装済み機能 (Completed)

- [x] **CLI 基盤**: `clap` v4 による引数・オプション・ヘルプ・バージョンパース。
- [x] **最前面 GUI**: `eframe` / `egui` による Always-on-Top ウィンドウ生成。
- [x] **即時キーボード終了**: `Esc` / `Enter` キーでの瞬時終了。
- [x] **柔軟なカラーパーサー**: 基本色名、和名、タイポ補正、1文字略称、HEXコード対応。
- [x] **プリセットサイズ & フォントサイズ指定**: `small`, `medium`, `large` および `--font-size`。
- [x] **点滅アニメーション**: `--blink` による明滅エフェクト。
- [x] **遅延タイマー & 時刻指定 (`--delay <秒数|HH:MM|単位>`)**: 指定秒数、時刻（`12:00`）、単位（`10m`/`1h`）で差分秒数を自動計算し、ゼロ負荷スリープ待機（最大24時間/86400秒対応）。
- [x] **複数行テキスト折返し最適化**: 長文や改行メッセージ時の自動ワードラップと水平・垂直中央揃え。
- [x] **アイコン表示オプション (`--icon <info|warn|error|ok>`)**: メッセージ左側にベクターシンボルアイコンを表示する機能。
- [x] **テーマ設定 (`--theme <system|dark|light>`)**: OS連動/ダーク/ライトのカラーパレット自動切替。
- [x] **マルチモニター・アクティブ画面検出**: 操作中マウスカーソルのあるディスプレイ（作業領域）の中央にポップアップを表示（Windowsネイティブ座標対応）。
- [x] **明示的なモニター指定オプション (`--monitor <cursor|primary|0|1...>`)**: 複数ディスプレイ環境で表示先モニターを番号やキーワード（`primary`等）で明示指定する機能。
- [x] **自動消去タイマー (`--timeout <秒>`)**: キー入力を待たずに指定秒数経過後に自動でウィンドウを閉じる機能（0で無効・手動終了待機）。
- [x] **OS標準トースト通知モード (`--toast` / `-T`)**: GUIウィンドウを立ち上げずにOSネイティブのトースト通知（通知センター）を発行する機能。
- [x] **日本語フォント自動検出**: OS システムフォントの自動登録による文字化け防止。
- [x] **単体テストスイート**: 主要パーサー・計算関数の自動テスト。

## 2. 今後の拡張計画 (Planned Roadmap)

### Phase 2: ディスプレイ・配置・プロセス制御の拡張
- [ ] **親プロセス・アクティブウィンドウ追従 (`--attach-parent`)**: コマンドを実行したターミナル/コンソールウィンドウの中央にポップアップを配置するオプション。
- [ ] **シングルトン / 二重起動防止・置換 (`--single-instance` / `--replace`)**: 既存の MyMsg ウィンドウが存在する場合に古いウィンドウを閉じて置き換える、または重複起動を防止するオプション（定期実行時のウィンドウ滞留防止）。
- [ ] **ヘッドレス / 非対話セッション（Session 0）検出**: GUI が表示できない環境で起動された場合に警告ログを出力、またはトースト通知/ログへ自動フォールバックする機能。
- [ ] **非Windows環境 (macOS / Linux) でのマルチモニター検出**: macOS (CoreGraphics) や Linux (X11 / Wayland) でのアクティブモニター検出サポート。

### Phase 3: 音声・通知・タイマー演出の拡張
- [ ] **通知音オプション (`--sound` / `--beep`)**: ポップアップ表示時にビープ音やシステム通知音を鳴らす機能。
- [ ] **タイムアウト・プログレス表示 (`--show-progress`)**: `--timeout` 指定時に残り時間を視覚的に示すプログレスバーまたはカウントダウン秒数をUI上に表示する機能。

### Phase 4: インタラクション & ユーティリティ
- [ ] **クリップボードコピー / アクションボタン (`--copy`, `--action <cmd>`)**: ポップアップ上のボタンからメッセージをクリップボードにコピーしたり、外部コマンドを実行する機能。
- [ ] **ログファイル出力 (`--log <file>`)**: ポップアップの表示履歴や起動時刻、終了時刻を指定ログファイルに追記する機能。
- [ ] **透過ウィンドウ・アクリル効果 (`--transparent`)**: 背景半透明化やフロストガラス効果の実験的サポート。
- [ ] **カスタムアイコン指定**: 任意の絵文字や文字シンボルの直接指定。

### Phase 5: CI/CD & 配布
- [ ] **GitHub Actions 自動ビルド & リリース**: Windows/macOS/Linux 向けマルチプラットフォームクロスコンパイル。
- [ ] **パッケージマネージャー対応**: `winget`、`Scoop`、`Homebrew` への登録。

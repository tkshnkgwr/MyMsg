## 1. 実装済み機能 (Completed - v0.1.0)

- [x] **CLI 基盤**: `clap` v4 による引数・オプション・ヘルプ・バージョンパース。
- [x] **最前面 GUI**: `eframe` / `egui` による Always-on-Top ウィンドウ生成。
- [x] **即時キーボード終了**: `Esc` / `Enter` キーでの瞬時終了。
- [x] **柔軟なカラーパーサー**: 基本色名、和名、タイポ補正、1文字略称、HEXコード対応。
- [x] **プリセットサイズ & フォントサイズ指定**: `small`, `medium`, `large` および `--font-size`。
- [x] **点滅アニメーション**: `--blink` による明滅エフェクト。
- [x] **遅延タイマー**: `--delay` (0〜3600秒安全クランプ) と GUI 非生成スリープ。
- [x] **日本語フォント自動検出**: OS システムフォントの自動登録による文字化け防止。
- [x] **単体テストスイート**: 主要パーサー・計算関数の自動テスト。

## 2. 今後の拡張計画 (Planned Roadmap)

### Phase 2: 音声・通知機能の拡張
- [ ] **通知音オプション (`--sound` / `--beep`)**: ポップアップ表示時にビープ音やシステム通知音を鳴らす機能。
- [ ] **自動消去タイマー (`--timeout <秒>`)**: キー入力を待たずに指定秒数経過後に自動でウィンドウを閉じる機能。

### Phase 3: GUI レイアウトの高度化
- [ ] **複数行テキスト折返し最適化**: 長文メッセージ時の自動ワードラップと縦スクロール対応。
- [ ] **アイコン表示オプション (`--icon <info|warn|error|ok>`)**: メッセージ左側にベクターアイコンを表示する機能。
- [ ] **透過ウィンドウ・アクリル効果 (`--transparent`)**: 背景半透明化やフロストガラス効果の実験的サポート。

### Phase 4: CI/CD & 配布
- [ ] **GitHub Actions 自動ビルド & リリース**: Windows/macOS/Linux 向けマルチプラットフォームクロスコンパイル。
- [ ] **パッケージマネージャー対応**: `winget`、`Scoop`、`Homebrew` への登録。

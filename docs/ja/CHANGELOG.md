## [1.4.0] - 2026-10-02

### 変更・改善 (Changed & Improved)
- **定期実行（`--interval`）における直感的な操作体系の確立**:
  - 通知表示時に `Enter` キー（または「✓ 今回閉じる」ボタン）を押すことで「今回閉じて次回待機」へスムーズに移行できるよう改善。
  - `Esc` キー（または「✕ 中止」ボタン）を押した場合は、いつでも定期実行を即座に中断してプロセスを完全終了できるようキー割り当てを整理。
  - 定期実行継続中（次回待機あり）の場合、画面右下に「✓ 今回閉じる ({}/{}回) [Enter]」と「✕ 中止 [Esc]」の2ボタンを表示し、マウス操作でも直感的に選択可能に改善。
- **指定時刻通知（`--at`）のシンプル化とバリデーション強化**:
  - これまでの複数時刻指定を廃止し、1日の中の特定時刻を1つのみ指定する単発スケジュール仕様へ簡素化。
  - カンマ区切り等の複数時刻や不正な時刻書式が渡された場合に、親切なエラーメッセージを表示して終了（Exit Code 1）するガード処理を追加。
- **Windowsメッセージポンプのフラッシュ処理追加**:
  - ウィンドウ破棄直後に未処理の Windows OS メッセージをフラッシュ（`PeekMessageW` / `TranslateMessage` / `DispatchMessageW`）し、残存イベントによる予期せぬ動作を防止。

### ドキュメント (Documentation)
- **UPX圧縮時の起動遅延・誤検知に関する注意喚起を追加 (`RELEASE.md`)**:
  - 起動時のメモリ展開によるタイムラグ（もたつき）や、セキュリティソフトによる誤検知リスクを明記。
- **高精度CLIベンチマークセクションの新設 (`FOOTPRINTS.md`)**:
  - モダンベンチマークツール `hyperfine` による実測値（平均実行時間・標準偏差・最小〜最大範囲）および測定手順を追記。

## [1.3.0] - 2026-09-29

### 追加 (Added)
- **タスクスケジューラ / ダブルクリック単独起動時のDOS窓自動消去 (`auto_detach_console_if_standalone`)**:
  - `GetConsoleProcessList` により、自分専用に新規生成されたコンソール（属するプロセスが1つのみ）であるかを起動直後に自動判別。
  - タスクスケジューラ等からの単独起動時は即座に `FreeConsole()` を呼び出して黒いDOS窓を自動消去し、GUIポップアップのみをスマートに表示。
  - ターミナル（PowerShell / cmd）から起動された場合は既存コンソールを維持し、CUIとして同期実行・プロンプト即時復帰を完全両立。
- **アクティブデスクトップ（`Default`）検証 & 隔離環境検出**:
  - `GetThreadDesktop` および `GetUserObjectInformationW` により、現在のスレッドがアクティブな `Default` デスクトップにアタッチされているかを厳格に検証。
  - AntiGravity などのサンドボックス環境（`exebox-...`）や非対話環境を確実に検知し、OSトースト通知モード（`--toast`）へ自動フォールバック。
- **ウィンドウ生成失敗時のトースト自動フォールバック（二重フェイルセーフ）**:
  - `eframe::run_native` でのコンテキスト生成失敗時でも通知が失われないよう、即座に OS トースト通知を送信して安全に終了するフェイルセーフを追加。
- **Obsidian Vault 一時メモ保存スキルの追加**:
  - `.agents/skills/vault-memo/SKILL.md` を追加し、アイデアやメモの自動Vault格納をサポート。

### 変更・改善 (Changed & Improved)
- **ドキュメント全面刷新**:
  - `README.md` および `README_JA.md` を最新仕様（全オプション一覧・豊富な使用例・ドキュメント索引）で完全再作成し、テーブルの垂直整列（gVim視認性）を適用。
  - 著作権者表記を `tkshnkgwr` に統一。

## [1.2.0] - 2026-09-07

### 追加 (Added)
- **通知音オプション (`--sound` / `--beep`)**:
  - ポップアップ表示時およびトースト通知発行時に OS のシステムチャイム音（Windows `MessageBeep` 等）を再生。`--icon` の種別（情報・警告・エラー・成功）に応じて音色を連動。
- **ヘッドレス / 非対話セッション（Session 0）自動検出 & フォールバック**:
  - Windows サービスやバックグラウンドタスクスケジューラ等のデスクトップ非表示環境を自動検知し、標準エラー出力への警告およびトースト通知モード（`--toast`）への自動フォールバックを実行。

### リファクタリング (Refactored)
- **CLI モジュールの分割再編**:
  - 肥大化した `src/cli.rs` を責務別のサブモジュール群（`src/cli/args.rs`, `types.rs`, `time.rs`, `layout.rs`, `mod.rs`）へ分割し、保守性を向上（完全な後方互換性を維持）。

## [1.1.0] - 2026-09-07

## [1.0.0] - 2026-08-31


### 追加 (Added)
- **明示的なモニター指定オプション (`--monitor <cursor|primary|0|1...>`)**:
  - `EnumDisplayMonitors` による複数ディスプレイの列挙と、マウスカーソル位置（既定）、プライマリモニター（`primary`）、およびモニター番号による確実な表示先指定に対応。
- **自動消去タイマーオプション (`--timeout <秒>`)**:
  - 指定秒数経過後に自動でウィンドウを閉じる機能を追加（デフォルト `0` は手動終了まで常時表示）。
- **OS標準トースト通知モード (`--toast` / `-T`)**:
  - `notify-rust` クレートを導入し、GUI ウィンドウを立ち上げずに OS ネイティブのトースト通知（Windows 通知センター / macOS / Linux）を発行して即時終了するモードを追加。
- **遅延タイマーの時刻指定 (`HH:MM` / `HH:MM:SS`) & 単位指定 (`10m`, `1h`, `10分`)**:
  - `chrono` クレートによる現在時刻との差分秒数自動算出および翌日繰り越し計算に対応。
- **遅延タイマー上限の拡張**:
  - 最大待機時間を従来の 1 時間（3,600秒）から **24 時間（86,400秒）** に拡張。
- **CLI ヘルプ（`-h` / `--help`）の強化**:
  - 遅延・時刻指定の書式や使用例を詳細ヘルプに明記。
- **単体テストスイートの拡充**:
  - 時刻差分計算、翌日繰り越し、単位指定、モニター指定パースのテストを追加（計11件）。

## [0.1.0] - 2026-08-28

### 追加 (Added)
- **マルチモニター・アクティブディスプレイ自動検出**:
  - Windows API (`GetCursorPos`, `MonitorFromPoint`, `GetMonitorInfoW`) を使用し、現在マウスカーソルのあるディスプレイの作業領域（`rcWork`）の中央にポップアップを自動配置。
  - `eframe` の `centered: false` 設定と物理ピクセル座標計算により、プライマリモニターへの意図しない再移動・上書きを防止。
- **複数行テキスト折返し最適化 & 水平・垂直完全中央揃え**:
  - `egui::ScrollArea` と行ごとの中央配置による複数行・長文の見切れ防止と美しいレイアウト。
  - コマンドライン引数内の `\n` および `\r\n` エスケープ文字列の実改行展開。
- **通知アイコン表示オプション (`-i / --icon`)**:
  - `info` (ℹ), `warn` (⚠), `error` (✖), `ok` (✔) のシンボル表示と種別ごとの専用ハイライト色。
- **テーマ設定オプション (`-t / --theme`)**:
  - `system` (OSのダーク/ライト設定自動追従・既定)、`dark`、`light` のプリセット切替。
- **コア CLI エンジン**: `clap` v4 (derive マクロ) による引数パース。位置引数 `[MESSAGE]` および `-m / --message` オプションに対応。
- **最前面固定 GUI 通知**: `eframe` / `egui` を用いた Always-on-Top ウィンドウのネイティブ生成。
- **キーボード即時終了**: `Esc` または `Enter` キー押下、あるいは下部閉じるボタンクリックによる瞬時プロセス終了（終了コード 0）。
- **柔軟なカラーパーサー (`parse_color`)**:
  - 24種類以上の標準色名（`red`, `green`, `blue`, `gold`, `crimson`, `navy` 等）。
  - 日本語色名（`赤`, `青`, `緑`, `黄`, `白`, `黒`）。
  - タイポ自動補正（`bule` → 青）。
  - 1文字略称（`r`, `g`, `b`, `y`, `w`, `k`, `c`, `m`, `o`, `p`）。
  - HEXコード（`#RGB`, `#RRGGBB`, `#RRGGBBAA`、先頭 `#` 省略可）。
- **ウィンドウサイズプリセット & フォントサイズ指定**:
  - `small` (300x150, 20pt), `medium` (450x220, 26pt, 既定), `large` (650x350, 36pt)。
  - `--font-size <pt>` による文字サイズの直接指定。
- **緊急点滅モード (`-b / --blink`)**:
  - 約0.5秒周期で文字アルファ値を明滅させるエフェクト。
- **ゼロ負荷遅延タイマー (`-d / --delay`)**:
  - 指定秒数待機後に最前面表示（0〜3600秒安全クランプ）。待機中は GUI 非生成でリソース消費ゼロ。
- **日本語フォント自動検出・登録 (`setup_japanese_fonts`)**:
  - Windows/macOS/Linux の OS 標準日本語フォントを自動検出し、文字化け（豆腐化）を完全防止。
- **包括的な単体テストスイート**:
  - カラーパース、引数優先度、遅延クランプ、ウィンドウ寸法計算のテストを完備。

## [0.1.0] - 2026-08-28

### 追加 (Added)
- **コア CLI エンジン**: `clap` v4 (derive マクロ) による引数パース。位置引数 `[MESSAGE]` および `-m / --message` オプションに対応。
- **最前面固定 GUI 通知**: `eframe` / `egui` を用いた Always-on-Top ウィンドウのネイティブ生成。
- **キーボード即時終了**: `Esc` または `Enter` キー押下、あるいは下部閉じるボタンクリックによる瞬時プロセス終了（終了コード 0）。
- **柔軟なカラーパーサー (`parse_color`)**:
  - 24種類以上の標準色名（`red`, `green`, `blue`, `gold`, `crimson`, `navy` 等）。
  - 日本語色名（`赤`, `青`, `緑`, `黄`, `白`, `黒`）。
  - タイポ自動補正（`bule` → 青）。
  - 1文字略称（`r`, `g`, `b`, `y`, `w`, `k`, `c`, `m`, `o`, `p`）。
  - HEXコード（`#RGB`, `#RRGGBB`, `#RRGGBBAA`、先頭 `#` 省略可）。
- **ウィンドウサイズプリセット & フォントサイズ指定**:
  - `small` (300x150, 20pt), `medium` (450x220, 26pt, 既定), `large` (650x350, 36pt)。
  - `--font-size <pt>` による文字サイズの直接指定。
- **緊急点滅モード (`-b / --blink`)**:
  - 約0.5秒周期で文字アルファ値を明滅させるエフェクト。
- **ゼロ負荷遅延タイマー (`-d / --delay`)**:
  - 指定秒数待機後に最前面表示（0〜3600秒安全クランプ）。待機中は GUI 非生成でリソース消費ゼロ。
- **日本語フォント自動検出・登録 (`setup_japanese_fonts`)**:
  - Windows/macOS/Linux の OS 標準日本語フォントを自動検出し、文字化け（豆腐化）を完全防止。
- **包括的な単体テストスイート**:
  - カラーパース、引数優先度、遅延クランプ、ウィンドウ寸法計算のテストを完備。
